# Data Formats Guide

## Overview

ISO-DART saves all data in CSV format for maximum compatibility with analysis tools. This guide describes the structure and format of downloaded data files.

## General CSV Format

All CSV files have: - Header row with column names - UTF-8 encoding - Comma-separated values - ISO-8601 date/time formats where applicable

## File Naming Conventions

### CAISO

` {start_date}_to_{end_date}_{query_name}_{data_item}.csv `

Examples: ` 20240101_to_20240131_PRC_LMP_TH_NP15_GEN-APND.csv 20240101_to_20240131_SLD_FCST_CAISO_forecast.csv 20240101_to_20240131_ENE_WIND_SOLAR_SUMMARY_WIND_TOTAL_GEN_MW.csv `

### MISO

` miso_{data_type}_{date}.csv `

Examples: ` miso_da_exante_lmp_2024-01-01.csv miso_fuel_mix_2024-01-01.csv miso_rt_actual_load_2024-01-01.csv `

### NYISO

` {start_date}_to_{end_date}_{dataid}_{aggregation}.csv `

Examples: ` 20240101_to_20240131_damlbmp_zone.csv 20240101_to_20240131_rtfuelmix.csv 20240101_to_20240131_pal.csv `

### SPP

` {start_date}_to_{end_date}_SPP_{market}_{data_type}_{location_type}.csv `

Examples: ` 20240101_to_20240131_SPP_DA_LMP_SL.csv 20240101_to_20240131_SPP_RTBM_MCP.csv 20240101_to_20240131_SPP_Operating_Reserves.csv `

### BPA

` {year}_BPA_{data_type}.csv `

Examples: ` 2024_BPA_Wind_Generation_Total_Load.csv 2024_BPA_Reserves_Deployed.csv `

### PJM

` {start_date}_to_{end_date}_{endpoint}.csv `

Examples: ` 01-01-2024_to_01-31-2024_da_hrl_lmps.csv 01-01-2024_to_01-31-2024_hrl_load_metered.csv `

### Weather

` {start_date}_to_{end_date}_{station_name}_{state}.csv `

Examples: ` 2024-01-01_to_2024-01-31_San_Francisco_International_Airport_CA.csv `

## Data Schemas

### CAISO LMP Data

File Pattern: *_PRC_LMP_*.csv

Column | Type | Description | Example |

|--------|——|-------------|———| | INTERVALSTARTTIME_GMT | datetime | Interval start (GMT) | 2024-01-01T08:00:00Z | | INTERVALENDTIME_GMT | datetime | Interval end (GMT) | 2024-01-01T09:00:00Z | | OPR_DATE | date | Operating date | 2024-01-01 | | INTERVAL_NUM | integer | Hour ending (1-24) | 1 | | NODE_ID_XML | string | Node ID (XML format) | TH_NP15_GEN-APND | | NODE_ID | string | Node ID | NP15 | | NODE | string | Node name | NP15_GEN | | MARKET_RUN_ID | string | Market type | DAM | | DATA_ITEM | string | Data item identifier | TH_NP15_GEN-APND | | VALUE | float | LMP value ($/MWh) | 32.45 | | MLC | float | Marginal Loss Component | 0.23 | | MCC | float | Marginal Congestion Component | 1.12 |

Sample Data: `csv OPR_DATE,INTERVAL_NUM,DATA_ITEM,VALUE,MLC,MCC 2024-01-01,1,TH_NP15_GEN-APND,32.45,0.23,1.12 2024-01-01,2,TH_NP15_GEN-APND,29.87,-0.45,0.89 `

### CAISO Load Forecast

File Pattern: *_SLD_FCST_*.csv

Column | Type | Description | Example |

|--------|——|-------------|———| | INTERVALSTARTTIME_GMT | datetime | Interval start | 2024-01-01T08:00:00Z | | OPR_DATE | date | Operating date | 2024-01-01 | | INTERVAL_NUM | integer | Hour ending | 1 | | TAC_AREA_NAME | string | Area name | CAISO | | MARKET_RUN_ID | string | Market type | DAM | | VALUE | float | Load (MW) | 28500.0 |

### CAISO Wind/Solar Summary

File Pattern: *_ENE_WIND_SOLAR_SUMMARY_*.csv

Column | Type | Description | Example |

|--------|——|-------------|———| | INTERVALSTARTTIME_GMT | datetime | Interval start | 2024-01-01T08:00:00Z | | OPR_DATE | date | Operating date | 2024-01-01 | | INTERVAL_NUM | integer | 5-min interval (1-288) | 97 | | DATA_ITEM | string | Data type | WIND_TOTAL_GEN_MW | | VALUE | float | Generation (MW) | 2450.0 |

Available DATA_ITEM values: - WIND_TOTAL_GEN_MW - Wind generation - SOLAR_TOTAL_GEN_MW - Solar generation - WIND_FORECAST_MW - Wind forecast - SOLAR_FORECAST_MW - Solar forecast

### MISO LMP Data

File Pattern: miso_*_lmp_*.csv

Column | Type | Description | Example |

### MISO Fuel Mix

File Pattern: miso_fuel_mix_*.csv

Column | Type | Description | Example |

Fuel Types: Coal, Gas, Nuclear, Wind, Solar, Hydro, Other

Zone Names: CAPITL, CENTRL, DUNWOD, GENESE, H.Q, HUD VL, LONGIL, MHK VL, MILLWD, N.Y.C., NORTH, O.H., PJM, WEST

### SPP LMP Data

File Pattern: *_SPP_*_LMP_*.csv

Column | Type | Description | Example |

|--------|——|-------------|———| | GMTIntervalEnd | datetime | GMT interval end | 2024-01-01T07:00:00 | | Settlement Location | string | Location name | KCPL.HSTNS5 | | Pnode | string | Physical node | KCPL.HSTNS5 | | LMP | float | Total LMP ($/MWh) | 28.45 | | MLC | float | Loss component | 0.34 | | MCC | float | Congestion component | 0.89 | | MEC | float | Energy component | 27.22 |

### SPP Operating Reserves

File Pattern: *_SPP_Operating_Reserves.csv

Column | Type | Description | Example |

|--------|——|-------------|———| | GMTIntervalEnd | datetime | 5-min interval end | 2024-01-01T00:05:00 | | Reserve_Type | string | Reserve product | RegUp | | Requirement_MW | float | Requirement (MW) | 450.0 | | Cleared_MW | float | Cleared (MW) | 465.0 |

Reserve Types: RegUp, RegDN, Spin, Supp

### BPA Data

File Pattern: *_BPA_Wind_Generation_Total_Load.csv

Column | Type | Description | Example |

|--------|——|-------------|———| | Date | date | Operating date | 1/1/2024 | | Hour | integer | Hour ending | 1 | | Wind | float | Wind generation (MW) | 3450.0 | | Load | float | Total load (MW) | 8200.0 |

### PJM LMP Data

File Pattern: *_da_hrl_lmps.csv

Column | Type | Description | Example |

|--------|——|-------------|———| | datetime_beginning_ept | datetime | Hour beginning (EPT) | 01/01/2024 00:00 | | pnode_id | integer | Pricing node ID | 51288 | | pnode_name | string | Node name | AECO-1 | | voltage | string | Voltage level | 500 | | equipment | string | Equipment type | ZONE | | type | string | Node type | ZONE | | zone | string | Zone name | AECO | | total_lmp_ept | float | Total LMP ($/MWh) | 32.45 | | congestion_price_ept | float | Congestion ($/MWh) | 1.23 | | marginal_loss_price_ept | float | Loss ($/MWh) | 0.67 | | system_energy_price_ept | float | Energy ($/MWh) | 30.55 | | row_is_current | string | Current flag | True |

### Weather Data

File Pattern: *_{station}_{state}.csv

Column | Type | Description | Example |

|--------|——|-------------|———| | time | datetime | Hourly timestamp | 2024-01-01 00:00:00 | | temperature | float | Temperature (°F) | 45.3 | | dew_point | float | Dew point (°F) | 38.2 | | relative_humidity | float | Humidity (%) | 75.0 | | precipitation | float | Precip (inches) | 0.02 | | wind_speed | float | Wind speed (mph) | 12.5 | | wind_dir | float | Wind direction (degrees) | 225.0 | | air_pressure | float | Pressure (inHg) | 30.15 | | weather_condition | string | Condition | Cloudy |

## Working with Data

### Loading in Python

```python import pandas as pd

# CAISO LMP df = pd.read_csv(‘data/CAISO/20240101_to_20240131_PRC_LMP_TH_NP15_GEN-APND.csv’) df[‘OPR_DATE’] = pd.to_datetime(df[‘OPR_DATE’])

# MISO with datetime index df = pd.read_csv(‘data/MISO/miso_da_exante_lmp_2024-01-01.csv’) df[‘interval’] = pd.to_datetime(df[‘interval’]) df.set_index(‘interval’, inplace=True)

# Weather data df = pd.read_csv(‘data/weather/2024-01-01_to_2024-01-31_San_Francisco_CA.csv’,

index_col=’time’, parse_dates=True)
```

## Time Zones

### CAISO - All times in Pacific Time (PT) - GMT columns provided for UTC reference - Handles DST automatically (23 or 25 hours)

### MISO - All times in Central Time (CT) - ISO 8601 format with UTC offset

### NYISO - All times in Eastern Time (ET) - Time zone column included

### SPP - GMT timestamps - Central Time implicit

### PJM - Eastern Prevailing Time (EPT) - Includes DST handling
